# 0.1.5 Android visual diagnostic

Optimized full ARM64 runtime, signed with the retained key. Experimental; no
RP6 graphics or stability test yet. 0.1.4 remains the device-tested baseline.

Install over 0.1.4 without clearing data. Start Quick Race and drive for about
20 seconds. Run scripts/android/capture_visual_fidelity.sh on the local Linux
desktop to collect the new capture into one archive. No Career progression.

Read docs/ANDROID_VISUAL_FIDELITY.md for capture limits and source findings.
No lighting fix or visual parity claim. Build/signature/checksum details are
recorded beside this file. APK is delivered directly through ChatGPT; no
GitHub binary release was created because available connector tools lack
release/asset-upload support. Game files and signing credentials are excluded.
